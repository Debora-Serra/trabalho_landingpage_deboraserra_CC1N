- O que estou aprendendo (matérias da faculdade) ---------- - - -

Experiência e Interface com o Usuário

Estuda como criar interfaces digitais intuitivas, acessíveis e agradáveis, proporcionando uma boa experiência aos usuários.

Desenvolvimento de Banco de Dados

Ensina a modelar, criar, organizar e manipular bancos de dados para armazenar e consultar informações.

Fundamentos da Computação

Apresenta os conceitos básicos da computação, incluindo a história dos computadores, seus componentes e os princípios de funcionamento dos sistemas computacionais.

Lógica para Computação

Desenvolve o raciocínio lógico e ensina a criar algoritmos para resolver problemas computacionais.

Textos Científicos

Ensina a produzir, estruturar e formatar textos acadêmicos e científicos seguindo normas e metodologias de pesquisa.

Construção de Software Web

Aborda o desenvolvimento de sites e aplicações para a internet utilizando tecnologias como HTML, CSS e JavaScript.
